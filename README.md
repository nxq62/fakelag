# FakeLag (Fabric, Minecraft 1.21.11)

Mod kliencki, dziala razem z modem Freecam (osobny mod, inne klawisze).

| Klawisz | Funkcja |
|---------|---------|
| L | HOLD: zatrzymuje pakiety wychodzace az do ponownego nacisniecia (auto-zwolnienie po 10 s) |
| ; | DELAY: opoznia kazdy pakiet o ustalony czas |
| ' | zmiana opoznienia DELAY: 100 / 250 / 500 / 1000 / 2000 ms |

Klawisze zmienisz w Opcje > Sterowanie > FakeLag.

HOLD sluzy do "zawieszenia sie" dla serwera: serwer przestaje dostawac Twoje ruchy.
Na Twoim ekranie postac nadal normalnie sie porusza (np. spada). Po zwolnieniu serwer dostaje
wszystko naraz i moze Cie cofnac albo naliczyc obrazenia od upadku.

Uzywaj na serwerach, gdzie takie modyfikacje sa dozwolone. Wiele serwerow ich zabrania.

Wersje: Minecraft 1.21.11, Java 21, Fabric Loader 0.19.5, Loom 1.14.10, Fabric API 0.141.6+1.21.11.
